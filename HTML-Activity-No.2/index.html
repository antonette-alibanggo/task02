Registration URL Encoding Example

URL encoding is used to represent special characters in a URL.

https://myschool.edu/events/register?event=SMCC%20CCIS%20Week%202025&section=A

%20 represents a space in a URL. For example, SMCC%20CCIS means SMCC CCIS.

HTML vs XHTML Example
