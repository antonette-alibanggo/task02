01 · Overview

What is CCIS Week?

Event Snapshot

  • DatesSept 22–26, 2025
  • VenueSMCC Main Campus
  • OrganizerCollege of CIS
  • Open toAll CCIS Students
  • EntryFree ✓

CCIS Week gathers students for five days of talks, competitions, and exhibits built by the college's own programs. Expect a coding hackathon, robotics demos, a cybersecurity session, and a showcase of student-built projects — capped off with an awarding night.

Registration URL Encoding Example

The highlighted %20 is URL encoding for a space character — browsers can't send raw spaces in a URL, so each one is escaped as %20 before the request is sent.

08 · Syntax Reference

HTML vs XHTML Example

HTML

<br>
<img src="images/logo.png" alt="Event Logo">

XHTML

<br />
<img src="images/logo.png" alt="Event Logo" />

HTML allows void elements like <br> to stay unclosed, while XHTML requires every element — even void ones — to be self-closed with a trailing />.
